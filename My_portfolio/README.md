## Preview

Open `index.html` in a modern browser. Bootstrap and Google Fonts load over the internet. Local custom styling and scripts are in `css/` and `js/`.

## Deploy to GitHub Pages

1. Create a public GitHub repository for this website.
2. Upload `index.html`, the `css`, `js`, and `assets` directories to the repository **root**.
3. Commit the files to the default `main` branch.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**, set `main`, and select `/ (root)`.
6. Save and open the GitHub Pages link shown in Settings → Pages once published.
7. Verify the personal favourites and test navigation on phone and desktop before sharing the live link.

The ZIP is not itself a deployed site.
